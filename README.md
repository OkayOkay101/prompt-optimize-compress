# คู่มือปรับแต่งและย่อ Prompt (Prompt Optimize & Compress)

> สรุปบทเรียนจากการทดสอบจริง 4 รอบกับ **Gemini 3.8 Flash** พร้อม Prompt สำเร็จรูปสำหรับนำไปใช้งานได้ทันที

🌐 **เว็บไซต์ทางการ:** [https://okayokay101.github.io/prompt-optimize-compress/](https://okayokay101.github.io/prompt-optimize-compress/)

---

## 🎯 เกี่ยวกับโครงการ

เมื่อเราสร้าง Prompt ที่ซับซ้อน มักจะเจอปัญหา 2 ด้านที่ขัดแย้งกัน:
1. **AI ตอบเพี้ยน/หลอน (Hallucination):** อ้างอิงลิงก์ผิดหน้า คำนวณตัวเลขไม่ตรงสูตร นำยอดสะสมมาเทียบกับยอดรายเดือน หรือดึงบทความเก่าที่หมดอายุมาอ้าง
2. **Prompt ยาวเกินไป (Token Heavy):** เปลืองต้นทุนและเวลาตอบ แต่เมื่อพยายามตัดทอนคำด้วยตัวเอง โมเดลกลับลืมคำสั่งหรือเงื่อนไขสำคัญ

โครงการนี้จึงแยกกระบวนการออกเป็น **2 เสาหลักที่ต้องทำตามลำดับ (Sequential Workflow)**:
```
Prompt เดิม ➔ Step 1: Optimize (แก้ให้แม่นยำ) ➔ Step 2: Compress (ย่อให้กระชับ) ➔ Step 3: ทดสอบเทียบผลลัพธ์
```
> ⚠️ **คำเตือนสำคัญ:** ห้ามทำทั้งสองอย่างพร้อมกัน เพราะการพยายามย่อคำพร้อมกับแก้บั๊กจะทำให้ได้ Prompt ที่สั้นลงแต่เพี้ยนหนักกว่าเดิม

## 🚀 วิธีใช้งาน Prompt สำเร็จรูป

1. **เปิดโมเดล AI ที่คุณถนัด** (เช่น Claude 3.5 Sonnet, ChatGPT GPT-4o หรือ Gemini 1.5/3.8 Flash)
2. **หากต้องการให้ตอบตรงหลักฐานขึ้น:** คัดลอกเนื้อหาจาก [`prompt-optimizer.md`](prompt-optimizer.md) วางลงในแชต แล้ววาง Prompt เดิมของคุณต่อท้าย
3. **หากต้องการย่อให้สั้นลง:** คัดลอกเนื้อหาจาก [`prompt-compressor.md`](prompt-compressor.md) วางลงในแชต แล้ววาง Prompt ที่ต้องการย่อต่อท้าย
4. **หากต้องการทั้งสองอย่าง:** ให้รัน **Optimizer** ก่อนจนได้ผลลัพธ์ที่ถูกต้อง จากนั้นนำผลลัพธ์ที่ได้ไปรันต่อด้วย **Compressor**

## 💡 7 กฎทองความซื่อตรง (Baseline Honesty Rules)

สกัดจากข้อผิดพลาดที่เกิดขึ้นจริงในการทดสอบ:
1. **ลิงก์ต้องตรง:** อ้าง URL ได้เฉพาะเมื่อหน้านั้นมีเนื้อหานั้นอยู่จริง ตรงแพลตฟอร์มและประเทศ
2. **ซื่อสัตย์เรื่องการเปิดเว็บ:** หน้าที่ AI ไม่ได้เปิดอ่านจริง ให้ต่อท้ายด้วย `(ยังไม่ได้เปิดยืนยัน)` และห้ามระบุวันที่
3. **ใช้เอกสารปัจจุบัน:** อ้างอิงจากหน้า Help / Documentation ปัจจุบันก่อนบล็อกประกาศเก่า
4. **ตัวเลขต้องตรงสูตร:** กำกับป้าย `(ประมาณการ)` แสดงสูตรคำนวณชัดเจน และผลลัพธ์ต้องเท่ากับสูตร
5. **หน่วยและช่วงเวลาตรงกัน:** จุดคุ้มทุนต้องใช้หน่วยเวลาเดียวกับต้นทุน (เช่น ต้นทุนต่อเดือน = จุดคุ้มทุนต่อเดือน)
6. **ไม่โมเมว่าเป็นมาตรฐานสากล:** เกณฑ์ที่ AI หรือบอร์ดกำหนดเอง ให้เรียกว่า `เกณฑ์ที่บอร์ดตั้ง`
7. **งดใช้คำเด็ดขาดเกินจริง:** ห้ามใช้คำว่า "ถาวร", "ทันที" หรือ "ที่สุด" หากไม่มีแหล่งอ้างอิงชัดเจน
